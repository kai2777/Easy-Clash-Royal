# Easy-Clash-Royal

本專案將《皇室戰爭》的經典對決移植為網頁版 3D 塔防遊戲，透過 **Vibe Coding** 的方式與 AI 協作開發完成。遊戲採非對稱對戰設計，由玩家操控「大皮槌」牌組，對抗由電腦操控的「速轉豬」牌組。

## 專案發想動機
近期在社群媒體上看到有人利用 GPT-6 Astra 透過 Vibe Coding 成功製作出高度還原的《皇室戰爭》遊戲，深受啟發。加上自己過去非常熱衷於這款遊戲，認為其「拉扯與預判」的核心機制極具挑戰性與趣味，因此決定以此作為本次網頁程式設計作業的主題。

考量到原版遊戲卡牌數量龐大，為確保在單一網頁中能達到極高的完成度與程式碼品質，決定將範圍精簡收斂。特別挑選了自己最愛玩的 **「大皮槌」** 卡組，對決遊戲中最經典的 **「速轉豬」** 卡組。

## 核心機制與特色
- **3D 幾何體角色**：利用 Three.js 的幾何體 (Primitives) 組合角色，取代 2D Sprite，使角色能接受打光、投射陰影並真實轉向。
- **4 張手牌輪轉系統 (Deck Cycling)**：還原原作機制，玩家雖擁有 8 張卡牌，但畫面下方手牌區僅維持 4 張，使用後依序抽牌遞補，考驗過牌與防守策略。
- **動態佈署陣地**：預設僅能在我方半場佈署，擊破敵方公主塔後，佈署區域會相應擴張解鎖至該側的敵方陣地。
- **進階狀態機 (State Machine)**：
  - **眩暈 (Stun)**：雷電法師登場瞬間施放範圍電擊，普攻具備真實的 0.5 秒「眩暈」效果（中斷敵方移動與攻擊，並重置攻擊冷卻）。
  - **衝刺免傷**：幻影刺客具備獨立的蓄力、衝刺與冷卻狀態，衝刺期間具備免傷效果。
- **尋路演算法與目標鎖定**：
  - `chooseTarget()` 每 0.16 秒進行 360 度重新評估，解決索敵死角問題。
  - 野豬騎士、攻城槌與冰人具備特殊 targeting filter，僅鎖定防禦塔與加農砲。
  - **滑牆機制 (Sliding Collision)**：解決角色在橋頭邊緣卡死的 3D 尋路 Bug。當碰撞到死區時，角色自動沿牆壁滑行。

## 開發技術
- **單一檔案架構**：純前端實作，所有 HTML 結構、CSS 樣式與 JS 邏輯皆封裝於 `index.html`。
- **Three.js**：渲染 3D 空間、建立幾何模型與場景打光。
- **遊戲迴圈 (Game Loop)**：使用 `requestAnimationFrame` 驅動狀態更新與畫面渲染。

## Vibe Coding 除錯歷程
本專案從一個簡陋雛形開始，透過反覆測試與 AI 指令微調，解決了多項核心難題：
1. **模型建構**：從無 3D 資源到引導 AI 利用 Three.js 幾何體拼湊出角色模型。
2. **演算法突破**：實作 360 度重新尋路與滑牆機制，解決「橋頭卡死」與「索敵死角」難題。
3. **邏輯補全**：修復皮卡超人擊破公主塔後對國王塔發呆的 Bug，並成功將視覺特效轉化為真實的物理狀態控制。
